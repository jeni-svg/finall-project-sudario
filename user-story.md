# User Stories
### Feature: Note

US1: As a student, I want to write and save important notes, thoughts, ideas, and reminders in a free space, so that I can keep all my key study information in one place.

US2: As a student, I want to edit my saved notes, so that I can update or refine my study information whenever necessary.

US3: As a student, I want to delete my saved notes, so that I can remove outdated or unnecessary reminders from my study space.

### Feature: Question Management
US1: As a student, I want to create and save custom questions (such as multiple choice or identification) with their corresponding answers, so that I can build personalized review materials.

US2: As a student, I want to view and edit my saved questions, so that I can review my question bank and fix any errors.

US3: As a student, I want to delete saved questions, so that I can remove items I no longer need to study.

### Feature:  Interactive Quiz and Results
US1: As a student, I want to start a randomized quiz using my saved questions, so that I can actively test my knowledge on my own materials.

US2: As a student, I want to navigate through questions or exit an active quiz, so that I have control over my self-assessment session.

US3: As a student, I want to view my quiz score, correct/wrong counts, and a comparison of my selected answers against the correct answers, so that I can evaluate my performance and learn from my mistakes.
